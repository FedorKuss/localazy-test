# Tasks App (Nuxt 3)

Small demo application built as part of a technical assignment.

## Features

- Task list with filtering and status counts
- Task detail page with edit functionality
- Create new tasks
- Loading, error and empty states

## Tech stack

- Nuxt 3
- Vue 3
- TypeScript
- Tailwind CSS

## Setup

```bash
pnpm install
pnpm dev
```
